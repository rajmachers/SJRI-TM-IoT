Revised Analytics Perspective & Recommendations

Perspective shift: Treat unknown anchors as unmapped operational spaces, then progressively normalize with alias-to-room master mapping.
Dwell governance: Keep 5-minute minimum stay rule to avoid corridor pass-through inflation and improve operational trust.
Utilization optimization: Flag assets with no meaningful zone change >24h / >72h / >7d for maintenance, parking discipline, or reassignment.
Flow orchestration: Integrate with next-gen Asset + Porter scheduling (book/assign/dispatch/return) using zone dwell + transition SLA.
Day-close control: Add assembly-point reconciliation so high-value assets are parked in expected zones except emergency overrides.
Emergency readiness: Continue Code Blue BLE proximity logic to identify nearest resources and improve response confidence.
Analytics blocks for final selection: (A) movement volume + reach time + stay time by period, (B) top transition corridors by period, (C) after-hours assembly-point majority, (D) unknown-zone alias conversion status, (E) parked-assets by no-change band (>24h, >72h, >7d).
